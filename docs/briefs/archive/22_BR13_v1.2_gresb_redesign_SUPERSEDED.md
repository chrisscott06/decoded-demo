## What's changed in v1.2

Major content + layout reset following review of the deployed v1.0 build. Six things shifted:

1. **Floor / Ceiling renamed to Defendable / Achievable** — analyst jargon out, plain English in.
2. **Achievable recalibrated** — from theoretical max (79) to realistic deliverables-based (~69). Critical scope sync locked the in-scope items.
3. **Star bands recalibrated to indicative** — quintile methodology surfaced honestly with caveat ("cutoffs shift each year as cohort improves"). No fixed band claims.
4. **Critical Dependencies removed from IVG-facing nav** — they're NZA internal working notes, surfaced only in the P09 tracker.
5. **Overview page redesigned** — split layout: left narrative (board-readable intro to GRESB) + right two stacked infographics (2025 result · 2026 forecast). Single page, scannable in 30 seconds.
6. **Aspects page redesigned** — Molson-pattern accordion with per-aspect colour theming. Each indicator gets a card with 4-panel detail (what it means / last year / what we need to do / evidence required). Action-needed indicators highlighted with bordered colour in the aspect's palette.

**What didn't change:** Tasks 1 and 2 are complete and clean (routes work, atomic components built). This brief reuses them. The work is **content and framing rebuild**, not architectural — atoms stay, data and copy get replaced.

## Page 2 — `/gresb/aspects` (the Molson-pattern Aspects page)

### Structure

```
[Sub-tabs row: Overview | Aspects (active) | Forward planning]
[Component toggle: Management 30pt | Performance 70pt | Residential 3.5pt]

[Aspect group header — e.g. "REPORTING · 3 indicators · 3.75pt"]
  [Indicator card] [collapsed]
  [Indicator card] [EXPANDED with 4-panel detail]
  [Indicator card] [collapsed]

[Aspect group header — e.g. "LEADERSHIP · 5 indicators · 5pt"]
  [Indicator cards...]
  
[Footer legend strip: card state legend]
```

### Component toggle behaviour

Default to **Management 30pt** on first visit. Toggle to switch to Performance or Residential. Three states preserved in URL via query param: `/gresb/aspects?component=management` (etc.). Active toggle: filled coloured pill in band-accent colour. Inactive: outline only.

### Aspect group header

Coloured bullet dot in aspect colour + aspect name in aspect colour (uppercase letterspaced) + indicator count + total points. 16px space below before first indicator card.

### Indicator card — collapsed state

Three visual states based on `priority` field in JSON:

**1. Action needed** (`priority: action-needed`):
- Background `#1a1f2e` (subtle elevation)
- Border **2px solid** in aspect colour
- Code pill: filled background in aspect tint colour (20% alpha), code text in aspect colour, monospace 11px, rounded-full 999px radius
- Title: 14px white
- Right side: small "action needed" tag (12px text in aspect colour, on aspect-tint background)
- Score snippet: e.g. `0 / 3.5 last year` in 11px grey
- Chevron right at end

**2. Standard / defending / easy-win / confirm-only** (`priority: defending|standard|easy-win|confirm-only`):
- Background `#1a1f2e`
- Border **1px solid** subtle grey `#2a3e5c`
- Code pill: same as action-needed (filled background in aspect tint, code in aspect colour)
- Title: 14px white
- Right side: small status tag (12px, low-contrast white/grey) — text varies by priority: "defending" / "easy win" / "confirm only" / "standard"
- Score snippet + chevron

**3. Retired / parked / non-scored** (`priority: retired|parked|non-scored`):
- Background `#1a1f2e` with **50% opacity** for retired/non-scored, 65% for parked
- Border 1px subtle grey
- Code pill: grey (`#6a7a8e30` background, `#b8c5d3` text)
- Title: 14px grey, **strike-through for retired**
- Right side: small grey tag — "retired 2026" / "parked → 2027" / "reporting only" / "non-scored"
- Chevron present but click does nothing useful (or shows minimal detail)

### Indicator card — expanded state

When user clicks an action-needed or standard card, it expands to reveal a 4-panel detail grid:

```
┌────────────────────────────────────┬────────────────────────────────────┐
│ WHAT IT MEANS                      │ LAST YEAR                          │
│ (whatItMeans field)                │ (decision2025 + score2025)         │
│                                    │                                    │
├────────────────────────────────────┼────────────────────────────────────┤
│ WHAT WE NEED TO DO                 │ EVIDENCE REQUIRED                  │
│ (whatWeNeedToDo field)             │ (evidenceRequired.description)     │
│                                    │ Validated: manual / automated      │
└────────────────────────────────────┴────────────────────────────────────┘
```

Panel headers: 10px uppercase letterspaced, in **aspect colour** (creates visual continuity with the card border / pill).

Panel content: 12px grey-white (`#b8c5d3`), line-height 1.5.

Within the detail, certain inline emphasis uses the aspect colour for decision verdicts:
- "Accepted" / "MAXED" → green inline span
- "Partially Accepted" → amber inline span
- "Not Accepted" / "Not scored" → coral/red inline span

For indicators with `whatsChanged2026` populated, render a small banner above the 4-panel grid:
- "**Changed for 2026:** Weight DOUBLED — 0.5pt → 1pt"
- Background: amber-tint, border-left 3px amber

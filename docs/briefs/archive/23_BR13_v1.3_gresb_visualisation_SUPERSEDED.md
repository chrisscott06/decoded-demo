## What's changed in v1.3

Three things shifted from v1.2:

1. **Numbers recalibrated** against the vintage audit. Defendable 45 / Target 62 / Achievable 62 / Stretch 65. The earlier 69 ceiling didn't reflect that the new ESG/Net Zero policies can't be backdated to CY2025 — Anna's existing policy supply delivers ~+1.5pt this cycle, not +3.5pt.
2. **Forward Planning page redesigned** — from boring list of cards to a "point build-up" waterfall visualisation that shows the multi-year climb from 1-star → 4-star, with every action labelled as a contributing block. Plus layperson narrative + cycle cards + 5-star caveat + "not pursuing" pills.
3. **Aspects page visual polish** — eight design enhancements layered onto the existing Molson-pattern (icons, verdict banners, GRESB-tracked-issues chips, action checklists, document type icons, "what's changed for 2026" banner, peer comparison data, metadata footer). Plus non-scored / retired / parked cards become clickable too.

**What didn't change:** routes, atomic components, overall page architecture. This is content + visual layer work on top of the v1.2 foundation.


**Implementation:**
- SVG-based chart spanning full content width, ~600px tall
- Bottom-to-top progression (blocks stack upward)
- Each block:
  - Rectangle in cycle colour (defendable = grey-50, 2026 = coral, 2027 = teal, 2028 = green-muted)
  - Height proportional to point contribution (1pt = ~6px tall)
  - Width fixed (e.g. 200px)
  - Text inside: action title + `+N.N pts` in aspect colour
  - Indicator code mini-pill in top-right corner if `indicator` field present
- Star threshold lines: dashed horizontal lines across the chart at 30, 55, 67, 80, 90
  - 1px dashed grey
  - Star icons + threshold label on the left margin
- Hover any block → tooltip showing full context (action, points, note, year, indicator)
- Click any block → navigate to `/gresb/aspects/{aspectCode}` with the relevant indicator pre-expanded
- Year-cycle bracket on the right side: vertical curly brace marking which blocks belong to which cycle, labelled "2026 · this cycle", "2027 · next step up", "2028 · into 4-star"

**Data source:** `forwardPlanning.waterfall.blocks` array in gresb.json. Each block has:
- `label` — text shown in the block
- `delta` — point contribution (positive for add, negative for structural loss)
- `baseline` — used for milestone blocks (2025 = 52, Defendable = 45, target points)
- `category` — controls colour (`baseline` / `baseline-adjustment` / `defendable` / `2026` / `2027` / `2028` / `target-2026` / `target-2027` / `target-2028`)
- `indicator` — optional GRESB indicator code(s) for hover detail + click-through
- `note` — short rationale shown in hover tooltip
- `starThreshold` — optional, marks blocks that represent crossing a star threshold

**Animation (optional but high-impact):** on first page load, blocks fade in from bottom upward with 50ms stagger between blocks. Adds gravity to the climb visual. Use Framer Motion (already in repo).

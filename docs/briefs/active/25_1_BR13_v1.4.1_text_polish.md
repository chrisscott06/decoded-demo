## New JSON structure: paragraphs + bullets in narrative sections

Both `overviewPageNarrative.sections[]` and `aspectsPageNarrative.sections[]` now support a richer schema. Each section can have:

| Field | Type | Render as |
|---|---|---|
| `heading` | string | Coral underline header |
| `paragraphs` | array of strings | Stacked paragraphs (12px, `#b8c5d3`, 12px gap between) |
| `bullets` | array of strings (optional) | Bullet list — disc bullet in aspect colour, 12px text |
| `paragraphsAfterBullets` | array of strings (optional) | More paragraphs after the bullets |

### Markdown rendering inside paragraphs and bullets

- `**text**` → `<strong>` in white (vs body text which is `#b8c5d3`)
- `*text*` → `<em>` italic in grey `#6a7a8e`

Use a minimal markdown renderer — no need for full markdown spec, just bold + italic inline.

**Below the bar (new):**

┌─────────────────┬─────────────────┬─────────────────┐
│ DEFENDABLE      │ TARGET          │ STRETCH         │

│ do-nothing floor│ everything in   │ if Tier C       │

**Styling per column:**
- `label` — 10px uppercase, letterspaced, grey `#6a7a8e`
- `value` — 24px white bold
- `caption` — 10px grey `#6a7a8e`, line-height 1.4

Three equal-width columns, 16px gap, top border 1px subtle grey separating from the bar above.

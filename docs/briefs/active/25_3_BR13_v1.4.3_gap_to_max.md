## What's changed in v1.4.3

Two content additions that close the loop on "everything in one window" — IVG team can read a card and know exactly what's going on without opening the GRESB portal or a benchmark report:

1. **`gapToMax` content on all 25 action-needed indicators.** For each one: what got us the partial score, what's missing for max, what's realistic this cycle, and why. Includes structural blockers where max isn't achievable (e.g. RES6 depends on existing contract clauses, RM6.4 needs paid specialist work parked to 2027).

2. **`whatLastYearSubmitted` content on 18 defending indicators with substantive prefilled GRESB responses.** Verbatim narratives quoted where they exist (RM6.1's CRREM stranding work, RM6.2's ESGH Steering Committee oversight, RM7's 20% BNG biodiversity strategy, TC2.2's Fuze action-plan process, etc.) Plus the multi-select lists IVG ticked (RM2's 10 governance systems, RM3.1's 17 social risk issues, SE3.2's H&W measures, SE6's supplier code topics, SE8's grievance characteristics, TC6.1's community engagement topics).

Result: every action-needed AND every meaningful defending indicator now shows the actual GRESB-portal answer plus the realistic path to max. Reader doesn't need to log in anywhere or open any other document.

`whatLastYearSubmitted` is already in the v1.4 schema — v1.4.3 just populates more indicators with it.

## Render rule — where the new content goes

In the LAST YEAR panel of the expanded card, after the existing content (verdict pill + validator reason + whatLastYearSubmitted + score), add a new subsection:

```
[everything that already renders]

──────────────────────────────────────

PATH TO MAX                        [coral 10px uppercase header in aspect colour]
{gapToMaxSummary}                  [12px white, bold-ish — the headline]

{gapToMaxDetail}                   [12px grey #b8c5d3, prose, line-height 1.5]
```

The horizontal separator (1px subtle grey line) visually delineates "what we did last year" from "what we'd need to do to get max". Header label "PATH TO MAX" in the aspect colour (same treatment as the other panel headers).

If `gapToMaxSummary` is missing (e.g. on retired / non-scored / parked indicators), don't render the section. Backward compatible.

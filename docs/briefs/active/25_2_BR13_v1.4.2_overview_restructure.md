## Overview narrative — new 5-section structure

Each section reads from `data.overviewPageNarrative.sections[]` with the existing schema (paragraphs / bullets / paragraphsAfterBullets). One section ("How it's scored") uses two bullet blocks — supported via new optional `bulletsAfter` and `paragraphsAfterBulletsAfter` fields.

### Schema extension for section 2

```json
{
  "heading": "How it's scored.",
  "paragraphs": ["Out of 100, across three components:"],
  "bullets": ["**Management (30 pt)** — policies...", ...],
  "paragraphsAfterBullets": ["Star ratings (1 to 5) are *relative*..."],
  "bulletsAfter": ["Top 20% globally → 5-star", ...],
  "paragraphsAfterBulletsAfter": ["The cohort keeps improving..."]
}
```

If `bulletsAfter` is missing or empty, render only the first 3 fields (backward compatible with sections 1, 3, 4, 5).

### Rendering order per section

1. Heading (coral underline)
2. `paragraphs[]` — stacked
3. `bullets[]` — disc bullets in aspect colour
4. `paragraphsAfterBullets[]` — stacked
5. `bulletsAfter[]` — disc bullets (if present)
6. `paragraphsAfterBulletsAfter[]` — stacked (if present)

Markdown rendering (bold + italic) applies throughout per v1.4.1 spec.

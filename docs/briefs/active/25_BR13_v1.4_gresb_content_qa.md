## New JSON fields the design needs to render

Six new optional fields per indicator. Where populated, render them in the detail panel. Where missing, fall back to v1.3 behaviour.

| Field | Where in panel | Type | Example |
|---|---|---|---|
| `validatorReason` | LAST YEAR — italic block below verdict pill | string | *"Does not support some of the selected personnel groups…"* |
| `whatLastYearSubmitted` | LAST YEAR — prose paragraph below validator reason | string | "Personnel ESG performance targets: Yes…" |
| `gresbTrackedIssues` | WHAT IT MEANS — chip grid below prose | array of {label, peerPercent, ivgClaimed?} | "Board of Directors (54%)", "C-suite (84%)"… |
| `peerComparison` | WHAT IT MEANS — small inline data points | array of {label, ivgValue, peerPercent} | "Net Zero policy: IVG No · Peer 90% Yes" |
| `whatWeNeedToDoChecklist` | WHAT WE NEED TO DO — numbered list | array of strings | "1. Confirm with HR which personnel groups…" |
| `openQuestionsForIVG` | bottom of expanded card, separate strip | array of strings | "❓ Which personnel groups currently have ESG-linked comp?" |

### Render rules

**`gresbTrackedIssues`** — chip grid:
- 3-4 chips per row, 11px text
- Aspect-colour outline (1px)
- Chip text: `Label (peerPercent%)` e.g. "Board of Directors (54%)"
- If `ivgClaimed: true`, render with filled aspect-colour background

**`peerComparison`** — inline rows:
- 11px text
- Format: `{label}: IVG {ivgValue} · Peer {peerPercent}%`
- Small inline horizontal bar showing gap (optional)

**`whatWeNeedToDoChecklist`** — numbered list:
- Numbers in aspect colour
- Each item own line
- 12px text, 1.5 line height

**`openQuestionsForIVG`** — strip below the 4-panel grid:
- Background `#1a1f2e` with amber-tint left border (3px)
- Header: "OPEN QUESTIONS FOR TOMORROW'S MEETING" in amber, 10px uppercase
- Each question prefixed with `?` icon (lucide HelpCircle)
- Only render if array length > 0

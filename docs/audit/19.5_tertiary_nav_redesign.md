✅ No pill background. Coral text + coral underline.

### 3. Inactive tabs render as muted-grey text only

Computed at 1920×1080 on inactive "Heating strategy" tab:

```

border-bottom: 2px solid transparent  (layout placeholder; invisible)
color: var(--text-muted-on-dark)
```

✅ No pill background. Transparent underline holds vertical layout so state flips don't shift the strip.

### 4. Hover state brightens text without changing underline

Inline `onMouseEnter` / `onMouseLeave` handlers on each tab: when inactive, `color` flips to `var(--color-theme-body)` (the unmuted cream); when active, hover is a no-op (already coral). `border-bottom` is never touched by hover. 180 ms transition on both `color` and `border-color`.

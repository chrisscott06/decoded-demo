## Part 3 — Nav alignment to body container

### END — 2026-06-03 (commit `72e30cd`)

**Diagnosis:** Brief 17.5.2's `.thematic-page-container` used `max-width: 1280px`. Nav inner-containers (.topnav-primary-inner, .topnav-secondary-inner, .subnav-inner) used `max-width: var(--app-content-max-width)` = 1600px. At 1920 viewport, this put nav content at x=160 while body content was at x=352 — 160-192 px misalignment depending on the exact element.

Worse, the PortfolioEnergy outer motion.div had `width: 100%` + `padding: 32px` with default `box-sizing: content-box`, creating a 64 px overflow that pushed the body container to x=352 instead of the expected x=320.

**Fix (two parts):**

1. **New token + cascade.** Declared `--nav-content-max-width: 1280px` in `:root`. Swapped `.topnav-primary-inner`, `.topnav-secondary-inner`, `.subnav-inner` from `var(--app-content-max-width)` (1600) → `var(--nav-content-max-width)` (1280). `.page` keeps `--app-content-max-width` (1600) so Site Detail's sidebar + main breadth is unaffected.

2. **`boxSizing: 'border-box'` on PortfolioEnergy motion.div.** Padding now shrinks the content area instead of expanding outside, eliminating the 64 px overflow. Body container now centres at x=320.

3. **Secondary nav -12 trick reimplemented as `transform: translateX(-12px)`.** The old `margin-left: -12px + width: calc(100% + 12px)` worked when max-width=1600 (wider than viewport content area). With max-width=1280, that math pushed the inner to viewport-left at x=20 instead of centred. Transform composes cleanly with `margin: 0 auto` centring.

**Falsifiability — text-edge x-coordinates (accounting for each element's `padding-left`):**

| Surface | 1920×1080 | 1440×900 |
|---|---|---|
| `.topnav-primary-link:first` ("Home") text edge | **320** ✓ | **80** ✓ |
| `.topnav-secondary-link:first` ("Map") text edge | **320** ✓ | **80** ✓ |
| Tertiary tablist `[role="tab"]:first` ("Consumption") text edge | **320** ✓ | **80** ✓ |
| `.thematic-page-container > h3:first` text edge | **320** ✓ | **80** ✓ |

All four bands share one left edge at exactly x=320 at 1920 (target ±2 px). At 1440, all at x=80 (target ≥80). PASS criteria 5 + 9 met.

# Demo template documentation

This directory is intentionally kept minimal in the demo. Briefs, audit
notes, and session history from the source client engagement were stripped
during the Phase 1 anonymisation pass.

If the demo template is extended in future, drop new briefs into
`docs/briefs/active/` and audit notes into `docs/audit/` matching the
NZA Development Bible pattern (see CLAUDE.md at the repo root for the
demo-template conventions).
